# ADBroom Launcher release notes

## 1.0.0 — 2026-10-23

First standalone release of ADBroom Launcher.

- Native Android TV home screen (Android 6.0+); no WebView, INTERNET permission, ads or analytics. The Mac app is not required.
- Grid/row layouts, favorites, custom names, collections, hidden apps and parental PIN.
- Appearance, wallpaper, clock, profile, language, input/network and optional media modules.
- Optional user-enabled Home routing and local revision-checked companion editor bridge.
- Stable focus highlights and lightweight card reuse while navigating grids and rows.
- Shared Android TV / magic wand icon with density-specific assets and a TV banner.
- Versioned APK and SHA-256 checksum on GitHub Releases under `launcher-v<version>` tags.
